Practice Planner
Coach Quick Guide

A shared planning tool for U6, U8 and U9 Grizzlies coaches.

U6-C1   |   U8-C1–C3   |   U9-C1–C5
What the planner does: Use one shared drill library while keeping practices organized by participating team. Practices can be for one team or a combination of teams, and saved plans include timing, drill descriptions, layouts and Print/PDF output.

1First-time sign-in

  1. Open the Practice Planner.
  2. Go to Settings > Cloud Sync.
  3. Enter your email and select Email Me a Sign-In Link.
  4. Open the email and use the sign-in link.
  5. If you are not yet a member, copy the displayed User ID and send it to Tyrone for activation.

2Set your default team

In Settings, choose your default team for new practices.

U6-C1U8-C1–C3U9-C1–C5

Your team is pre-selected when you start a practice, but you can add other teams for combined ice sessions.

3Create a practice

Select Plan a Practice, then enter:

  • Date, start time and end time (duration is calculated automatically)
  • Arena
  • Participating team(s)
  • Optional practice focus
  • Warmup / Stations / Game percentages (20% / 60% / 20% by default)
  • Station layout: Traditional or Vertical

For a combined practice, select multiple teams - for example U8-C1 + U8-C2.

4Choose the drills

The practice flow is:

Free Skate - Warmup - Stations - Game

Select drills from the shared library. The drill picker includes search, favourites, recent drills and an optional Source filter.

For stations, Focus and Station Layout are optional filters used only to narrow the available drills. Traditional layouts support the existing station arrangement; Vertical layouts support 1–4 vertical ice slices.

The finished plan shows the drill name, description and saved layout/sketch.

5Edit or sketch a drill

Open a drill and choose Edit Drill. Under Sketch my own drill you can use:

  • Full Ice, Half Ice, Corner or Center Ice templates
  • Freehand, X/O stamps, straight lines/arrows and adjustable curved lines/arrows
  • Black, red or blue ink; selectable line width and Solid/Dashed style
  • Select one item or drag-select multiple items, then Move, Copy or Delete
  • Undo and Clear

Existing editable sketches can be reopened with Edit existing sketch. Older flattened sketches can be used as a background and annotated. Choose Use This Sketch, then save the drill.

6Saved & recent practices

The home page and Saved Practices show which teams are participating.

U8-C2U8-C1 + U8-C3U9-C1

Saved Practices defaults to your configured default team. Use the Team filter to switch teams or choose All teams to remove the filter.

7Print or save as PDF

Open the finished practice and select Print / PDF.

The formatted plan includes the date, arena, teams, schedule, descriptions and drill layouts.

Tip: On most computers, choose Save as PDF in the printer window to create an electronic copy.

8Sharing practices

Practices can be shared between coaches. Team selections and drill information stay with the practice.

A coach can therefore build a joint U8-C1 + U8-C3 session once and share the completed plan.

9Cloud syncing

When signed in, drills and practices are stored in the shared Grizzlies cloud workspace. If another coach has recently made changes, use Settings > Cloud Sync > Sync Now.

If the browser still looks out of date on Windows, use Ctrl + Shift + R once to force-refresh the planner.

Quick workflow
Open Planner › Plan a Practice › Select Team(s) › Pick Warmup › Pick Stations › Pick Game › Review › Save › Print / Share
